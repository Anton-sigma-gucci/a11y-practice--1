# Accessible Alert

Практична робота №1 з проєктування доступного UI-компонента.

## Опис

Проєкт містить доступний компонент повідомлення (Alert), розроблений у Figma та реалізований за допомогою HTML5, CSS3 і JavaScript.

## Реалізовано

- семантична HTML-структура;
- `role="alert"`;
- підтримка навігації клавіатурою;
- стани кнопки Default, Hover, Focus та Disabled;
- доступна кнопка закриття з `aria-label`;
- закриття повідомлення за допомогою JavaScript;
- `meta description`;
- `robots.txt`.
